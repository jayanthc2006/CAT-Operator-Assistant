USE WHEN asked "What data did you use?" SAY: "It's synthetic, which the organisers allowed, but we designed it so the problem isn't trivial. It keeps the organisers' exact columns, adds extra signals, and includes things no model can see: hidden operator pace, machine condition, daily site disruption, about 10% per-task noise and random 15–60 minute delays. That's why the model can't be perfect. We also injected labelled anomalies, only to validate the detector, and seeded two training effects plus one training that deliberately had no effect." KNOW: 75 calendar days before the database is created, Sundays skipped → 64 working days (65 if the reset is on a Sat/Sun, which gives 1,574 sessions and slightly different metrics: reset on a weekday). Weather days: Sunny 34, Cloudy 11, Rainy 6, Windy 6, Foggy 5, Dusty 2. 36.9% of sessions have a safety alert. Seatbelt unfastened 7.9%. The planner baseline ignores skill, machine age, temperature, slope and pace by design, like a planning sheet. IF ASKED "How would it work with real CAT data?": "Map telematics fields to the same sessions schema, since the organisers' columns are already the core, retrain, and validate on real history."
